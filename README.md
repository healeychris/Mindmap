# Mindmap
A fully offline, single-file mind mapping tool. No cloud services, no dependencies, no install


Features:

Multiple root nodes; Colour categories; Cross-links with labels;
Node notes, project, owner; status fields; Tags;
Filter bar; Search; Auto layout; Minimap;
Undo/redo; PNG, Markdown; CSV export; JSON save/load;
Customisable background; Snap to grid; Multi-select; bulk ops;
Reparent by Ctrl+drag; Focus roots; Statistics dashboard;
Print support; Keyboard-driven workflow
