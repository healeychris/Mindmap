MindMap

Version 1.0.0

A fully offline, single-file mind mapping tool. No cloud services, no dependencies, no install — just save the HTML file and open it in any browser.

Created by Chris Healey, built with assistance from Claude (Anthropic).

Features

Multiple root nodes · Colour categories · Cross-links with labels · Node notes, project, owner & status fields · Tags · Filter bar · Search · Auto layout · Minimap · Undo/redo · PNG, Markdown & CSV export · JSON save/load · Customisable background · Snap to grid · Multi-select & bulk ops · Reparent by Ctrl+drag · Focus roots · Statistics dashboard · Print support · Keyboard-driven workflow

Tips

• Double-click the canvas to add a node at that spot
• Right-click any node for a context menu
• Scroll to zoom, drag canvas to pan
• Blue dot means the node has metadata or notes
• Status icons appear top-right on nodes
• Tags are comma-separated — press Enter to add
• Data auto-saves to browser localStorage
• Use Save JSON to back up or move between machines
• Shift+click to multi-select, then bulk-change colour, status or owner
• Ctrl+drag a node onto another to reparent it
• Use Focus to show/hide entire root trees
• Collapse All / Expand All in the View menu
• Snap to Grid in View for tidy alignment
